# [File Extensions]{#PAGE_HEADER}

This page describes the file extensions used by the Genero Business
Development Language.

**Extension**

**Type**

**Description**

`.4gl`

Text

BDL Source Module

`.42m`

Binary

Compiler BDL p-code module

`.per`

Text

BDL [Form Specification File](FormSpecFiles.html)

`.42f`

XML

Compiler form specification file

`.42s`

Binary

[Localized Strings](LocalizedStrings.html) compiled file

`.4st`

XML

[Presentation Styles](PresentationStyles.html) resource file

`.4sm`

XML

[StartMenu](StartMenus.html) resource file

`.4tm`

XML

[TopMenu](Topmenus.html) resource file

`.4tb`

XML

[ToolBar](Toolbars.html) resource file

`.4ad`

XML

[Action Defaults](ActionDefaults.html) resource file

`.sch`

Text

[Database Schema File](DatabaseSchema.html) - column types

`.str`

Text

[Localized Strings](LocalizedStrings.html) source file

`.val`

Text

[Database Schema File](DatabaseSchema.html) - form field attributes 

`.att`

Text

[Database Schema File](DatabaseSchema.html) - video attributes

`.42r`

Binary

Compiled BDL program

`.42x`

Binary

Compiler BDL p-code library

`.msg`

Text

[Message Definition](MessageFiles.html) source file

`.iem`

Binary

Compiled Message Definition file
